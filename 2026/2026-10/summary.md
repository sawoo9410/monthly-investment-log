WTI는 미·이란 교전 재개로 9/10 $102.48까지 튄 뒤 휴전 기대로 $91대로 돌아왔다([CNBC](https://www.cnbc.com/2026/09/10/iran-us-oil-hormuz-supply-trump-military-brent-wti.html), [Investing.com](https://www.investing.com/commodities/crude-oil-historical-data)).

한국은 코스피 6,687.21 → 7,003.74(**+4.73%**, [뉴스1](https://www.news1.kr/finance/market-exr/6309173))로 반등했고, 9/15\~10/1 코스닥이 +10%로 코스피(+5.7%)를 앞섰다([한국경제](https://www.hankyung.com/article/2026100209561)). 반도체 소부장 랠리가 중심이었다(9월 장비주 10종 평균 **+20.56%**, 소재주 5종 평균 +16.85%, KRX 반도체 지수 +14.28%, [이투데이](https://www.etoday.co.kr/news/view/2631047)). 원/달러는 구간 중 1,380원대 급등 구간이 있었으나([Businesskorea](https://www.businesskorea.co.kr/news/articleView.html?idxno=276835)) 양 끝은 1,350원대로 보합이었다.

#### 09.23 리얼티인컴(O) 14주 매수 (@77,248원, 1,081,472원) — 이번 구간 최대 매수

- **종목 선택 — 인컴 기조와 일관, 다만 금리 역풍 정면.** 9/8 월배당을 $0.2715로 인상(136번째)했고 9/30 기준일 보유분은 10월 배당 대상이다([PR Newswire](http://www.prnewswire.com/news-releases/136th-common-stock-monthly-dividend-increase-declared-by-realty-income-302872745.html)). 반면 리츠는 10년물 5% 상회 시 자본비용 부담이 커지는 구조이고, 9월 내내 Mizuho·Evercore·Scotiabank가 목표가를 낮췄다. "금리 인상 사이클 재개 국면에 금리민감 자산을 늘린" 판단으로, 결과적으로는 아직 역행 중이다.
- **비중 — 2.53% → 4.76%.** 수량이 2배 이상(11 → 25주) 늘어 토스 해외 자산 내 비중이 크게 올랐다. 평단은 주당 약 90,104원 → 82,904원으로 낮아졌다.
- **밸류에이션**: AFFO 가이던스 상향($4.44\~4.45, [Motley Fool](https://www.fool.com/investing/2026/08/06/realty-income-raised-its-2026-affo-guidance-heres-what-that-means-for-its-52-dividend/))에도 주가가 빠져 배수는 낮아졌으나, 구체 P/AFFO 수치는 확인하지 않아 판단 유보.

## 부록: 확인 필요 항목

1. **토스 평가금액은 API 산출값** — 앱 "평가금" 토글 원본이 아니라 토스 API 스냅샷(10/2 21:58) 수량 × 현재가 × 환율. 매수원가는 9/4 앱 원본값 + 원화 체결금액으로 이어붙인 값이라 앱 표시와 소액 오차 가능.
2. **환율 출처** — 투자봇 `last_fx.json`(1,359.7205, 10/2). 시중 매매기준율은 출처 간 값이 엇갈려(1,350.60 / 1,343.84 등) 본문에 인용하지 않았다.
3. **어보브반도체 현재가 계좌별 차이** — 토스 API 8,800원 vs 신한 앱 8,770원(KRX 10/2 종가). 각 계좌 소스를 그대로 사용(토스분 +9,000원 차이).
4. **토스 테슬라(TSLA) 0.002698주** — API에만 있는 소수점 잔량(약 $0.96). 기존 기록에 없어 제외.
5. **어보브반도체 급등 촉매** — 웹 조사에서 종목 고유 뉴스·EB 후속 공시를 찾지 못함.
