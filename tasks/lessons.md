# Lessons Learned — 교정 사항 누적

> 사용자로부터 교정받은 패턴을 기록한다.
> 세션 시작 시 반드시 이 파일을 검토하고 적용할 것.
> 단순 오타는 기록 불필요. **반복될 수 있는 패턴**만 기록.

---

## 데이터 처리

- 환율은 항상 사용자가 제공한 값을 사용할 것. 임의 환율 적용 금지.
- 현재가가 제공되지 않으면 평단 기준으로 산출하되, "확인 필요"에 명시.
- **폴더 라벨링 규칙**: 매월 1일 기준으로 작성. 폴더 YYYY-MM = 직전 달(M-1) 결산이 담긴다. 예: 2026-06 폴더는 2026년 5월 매매와 5월 말 보유 현황을 기록.
- 평단/평가금액은 사용자 원본에 표시된 값만 사용. 역산값(예: USD 평단을 평가금액/수량으로 역산)은 작성 지양.
- 손익 화면의 "매수금액/매수 평균가"는 **신규 매수금액이 아니라 매도분의 매입원가**일 수 있음 (신한/토스 모두 확인됨). 신규 매수 합계는 별도 체결내역 화면을 받아야 함.
- **토스 주문내역 날짜 처리**: 날짜 라벨(예: 6.11)은 그룹 첫 줄에만 표시되고, 라벨 없는 아래 행들은 모두 같은 날짜에 속함. 같은 날 같은 종목이 여러 건 분할 체결될 수 있음(2026-07 JEPQ 6.11 4건). 누락·중복 없이 종목별 합계가 보유 수량과 맞는지 반드시 교차검증.
- **토스 주문내역 제외 처리**: "구매 취소"(예: 엔비디아 1주 취소)는 미체결이므로 제외. "N주 판매 완료"는 매도. 당일 동일 종목 매도+매수(JEPI 2026-07 6.29)는 라운드트립(순변동 0)으로 보유 미반영하되 transactions에는 양건 기록.
- **토스 USD 종목 체결단가**: 토스 주문내역을 "원" 토글로 보면 주당 원화 체결가가 표시됨 → transactions.md에 원화 단가/금액으로 기록 가능(역산 아님, 화면 원본값).
- **토스 보유 "현재가" 토글**: 토스 보유 화면을 "현재가"로 보면 종목별 개별 평가금액이 아니라 **주당 현재가(원)** 와 당일 등락률만 표시됨(등락률은 손익률 아님, 전일 대비). 평가금액=수량×현재가(원), 손익=평가−평단(원)×수량으로 산출하고 "앱 개별 평가금액 미표시, 산출값" 주석. 개별 평가금액이 필요하면 "평가금" 토글 화면을 별도로 받을 것.
- **토스 "내 투자" 총액에 QQQI 포함**: 토스 상단 총 평가금액·총손익은 QQQI(가족 계좌분) 포함 값일 수 있음. QQQI 제외 종목의 수량×현재가 합과 총액을 비교하면 QQQI분(수량 미상)을 역으로 검증 가능(2026-08 확인: 총액−개별합≈QQQI어치).
- **GOOGL 등 매도가 원화-USD 편차**: 토스 원화 체결가(예: 2026-08 GOOGL 555,098원/주)는 원본으로 그대로 기록하되, USD 환산 시 해당 시점 시장가와 편차가 날 수 있음(환율 시점·환전 스프레드). **자동수정·보정 금지**, "확인 필요"로 보고하고 밸류 평가는 유보.
- **토스는 "평가금" 토글 화면을 요청할 것**: "현재가" 토글은 주당 현재가만 보여줘 개별 평가금액을 산출해야 하지만, "평가금" 토글은 종목별 **평가금액·손익·수익률을 앱 원본값**으로 준다(2026-09 확인). 데이터 요청 단계에서 미리 "평가금 토글로 찍어달라"고 명시하면 산출 주석·오차가 사라짐.
- **토스 QQQI 검증 공식 확립**: QQQI 수량·평가금액이 화면에 보이면 `앱 총액 − QQQI = 개별 합산`으로 교차검증 가능(2026-09: 차이 4원). 총손익도 동일 방식으로 검증. QQQI 24주 = 1,786,510원(2026-09-04).
- **예수금은 합계에 반영한다 (2026-09 확정)**: 증권사 예수금(신한 D+2, 토스 원화+달러)은 **평가금액 합계에 포함**하되, **손익·수익률 계산에서는 제외**한다(현금이므로). 토스 USD 예수금은 해당 회차 환율로 환산해 USD 자산에 넣는다. 2026-08까지는 소액이라 미반영했으므로, 전월 비교 시 **기준 차이를 각주로 명시**할 것(8/14 토스 예수금 약 8,582원). 과거 달 파일은 "최소 영향" 원칙에 따라 소급 수정하지 않는다.
- **한투 DCA 실행 여부는 trading 로그로 확인**: `investment-strategy-trading/logs/dca_buy_YYYYMMDD.log`에 `APBK0952`(잔액부족)가 찍히면 그날 매수 실패. 전 영업일 스캔하면 "매매 없음"을 근거 있게 단정할 수 있음. 한투 잔고 API가 500 에러로 실패하면 `daily_close` 로그가 config fallback 수량을 쓰므로, 수량은 DCA 성공 여부와 함께 봐야 함.

## 데이터 소스 (finance 폴더 연계)

- **investment-strategy 봇 = 1차 계좌 데이터 소스**: `config.yaml`(보유·평단·현금), `data/last_fx.json`(환율), `data/last_prices.json`(현재가), `data/asset_history.json`(일별 총자산), `logs/daily_close_*.log`(일별 스냅샷)에 실제 계좌 데이터가 있음. 토스·한투는 API 자동수집이라 신뢰도 높음.
- **⚠️ 신한 ISA는 config 수동관리 → 최신 아닐 수 있음**: 봇이 신한 API가 없어 config의 신한 수량을 수동 갱신함. 2026-08에 KODEX 449180이 config 290주였으나 실제 355주(+65 매수 미반영)였음. **신한 보유·수량·예수금은 항상 사용자 화면으로 확인**, config 값 맹신 금지.
- **매매 체결 내역은 봇에 없음**: 토스·신한의 개별 체결(일자·단가)은 저장 안 됨(investment-strategy-trading DB도 한투 DCA만·7/1까지). 매매내역은 사용자 스크린샷으로 받아 config 수량 변화와 교차검증.
- **스냅샷 기준 회차 가능**: 사용자가 "오늘자 기준"을 원하면 폴더는 다음 순번(YYYY-MM)에 쓰되, 파일 상단에 "월말 결산 아님, YYYY-MM-DD 스냅샷" 명시. 전월 비교는 직전 기록(월말) 대비로 수행.

## 종목 정보

- **449180.KS = KODEX 미국S&P500(H)**: 환헤지 ETF (2026-06 작업 중 확정).
- **360750.KS = TIGER 미국S&P500**: 환노출 ETF (2026-06 작업 중 확정).
- 한투의 449180.KS는 사용자가 영업일마다 1주씩 적립 매수하는 **DCA 종목** (2026-06 확인). 한투 매매내역은 기록 생략, 보유 현황만 기록.
- 신한 ISA에서 KODEX(환헤지)와 TIGER(환노출)를 병행 보유 → 환율 양방향 노출 의도로 해석.
- **QQQI는 사용자 자산에서 제외**(2026-07 명시). 토스 보유·주문내역에 QQQI가 나와도 holdings/transactions/summary 어디에도 기록하지 않음. 단 토스 "이번 달 N건"·판매수익 등 화면 집계값은 QQQI 포함일 수 있어 참고용으로만 인용.
- **어보브반도체는 토스(국내) + 신한 ISA 양 계좌 동시 보유**(2026-07 신규). 합산 수량으로 코멘트하고, 한 계좌만 보고 "전량/신규" 단정 금지.
- **어보브반도체(102120) 하락 이력**: 2026-07-30 5,730원 → 08-14 8,260원(+44.2% 급등) → 09-04 6,910원(-16.3%). 8/18 교환사채(EB) 풋옵션 120억원 행사 보도가 개별 악재(교환가 15,453원 대비 심한 언더워터). 자회사 윈팩(097800)이 EB 3회차 교환대상이라 동반 하락. **셀사이드 커버리지 0건** → 목표주가 컨센서스가 아예 없음("확인 불가"가 아니라 "해당 없음").

## 포트폴리오 관찰 (누적)

- 사용자는 증권사별로 성격을 분리 운용: 토스(USD 개별주/ETF), 신한 ISA(국내 ETF + 현금), 한투(소량 국내 ETF DCA).
- 신한 ISA의 현금(예수금) 비중 추이: 2026-05 36.2% → 2026-06 20.1% (감소 추세).
- 신한 ISA의 예수금은 D+1(매수가능액)과 D+2(결제 완료) 두 가지 표시. **D+2 기준으로 일관성 유지** (전월 비교 가능).
- 신한 ISA TIGER 미국S&P500의 매도-당일/직후 재매수 패턴 관찰 (2026-06 5.6, 5.28→5.29). ISA 비과세 한도 활용 또는 단순 차익실현+재진입 여부 확인 필요.
- **비투자 자산 트래킹**: 사용자는 증권 자산 외에 가용 현금/적금도 매월 기록. holdings.md 별도 섹션 + summary.md 3번에 반영. PORTFOLIO_HISTORY 비고에도 함께 표기. **투자 평가금액·수익률 계산에는 포함하지 않음** (성격 분리).

## 서브에이전트 운용

- **최종 보고는 자립형(self-contained)으로 요청할 것**: 서브에이전트가 중간에 재조사를 하면 마지막 메시지만 "앞선 보고서의 N번을 대체한다" 식 **정정판**으로 돌아와 본편 내용이 메인에 전달되지 않는다(2026-09 발생). 프롬프트에 "최종 답변은 앞선 내용을 참조하지 말고 전 항목을 한 번에 담아라"를 명시하거나, 누락 시 SendMessage로 재요청.
- **출처 충돌은 그대로 보고**: 서브에이전트가 같은 수치에 대해 상충하는 두 값을 가져오면(2026-09 어보브 2Q26 실적) 어느 쪽도 summary.md에 인용하지 말고 "확인 필요"로 넘길 것. 임의 채택 금지.
- **섹터 지수로 개별주 하락을 설명하지 말 것**: 2026-09 구간에 KODEX 반도체(091160)는 -1.98%였으나 이는 삼성전자·SK하이닉스 쏠림 탓이고, 실제로는 중소형 반도체 평균 -10.8%로 극단적 양극화였다. 지수 하나로 퉁치면 원인 진단이 틀어짐.

## 형식/톤

- **현금 비중 코멘트 시 적금(비투자 완충) 층위 구분**: 4-3에서 "현금 비중이 낮다/실탄 소진" 류를 쓸 때, 그 수치는 **투자 자산 내부 현금(신한 예수금 등) 기준**임을 명시하고, 별도로 존재하는 **적금(비유동 완충)** 을 함께 언급할 것. config의 현금 목표(cash_min 15~25%)도 *투자 포트 내 현금/CMA* 기준이라 적금과 층위가 다름. 적금을 빼놓고 "현금 목표와 벌어졌다"만 쓰면 "현금이 아예 없다"는 과장된 인상을 줌 (2026-08 교정). 특히 비투자 자산을 아직 못 받은 상태에서 초안을 쓰면 이 실수가 나기 쉬움 → 비투자값 확정 후 현금 코멘트 재점검.
